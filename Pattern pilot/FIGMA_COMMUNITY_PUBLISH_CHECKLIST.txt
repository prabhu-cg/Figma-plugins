  1. Choose a width: Mobile (375), Tablet (768) or Desktop (1440)

5. PUBLISH STEPS (Figma desktop app)
-------------------------------------------------------------------------------
  Menu names can shift between Figma versions; follow what the app shows.

  [ ] 1. Open Figma desktop and any Design file.
  [ ] 2. Plugins > Manage plugins (or the Resources panel > Plugins >
         Development). Find "Pattern Pilot" under In development.
  [ ] 3. Click the plugin's menu ("...") > Publish. The "Publish plugin" modal
         opens.
  [ ] 4. DESCRIBE: enter Name, Tagline, Description, Category (section 4).
  [ ] 5. IMAGES: upload Icon (128x128), Thumbnail (1920x1080), then carousel
         images (max 9) and an optional playground file (section 3).
  [ ] 6. DATA SECURITY (optional page): the security disclosure form is
         reviewed by Figma and "may take up to two weeks"; answers become
         visible to logged-in users. Pattern Pilot has no network access and
         collects nothing, so it is optional. Decide before submitting.
  [ ] 7. FINAL DETAILS:
         - Publish to: if you see "Organization" vs "Community" (only shown on
           Organization/Enterprise plans), choose COMMUNITY.
         - Publish as: yourself, or a team you are authorised to represent.
         - Support contact: the issue link from section 4.
         - Network access label: it should read "No access to network" if the
           manifest networkAccess is picked up. If it says "Unknown network
           access", re-check manifest.json has
           "networkAccess": {"allowedDomains": ["none"]} and re-import.
         - Additional contributors: none (optional).
         - Community comments: your choice (allow or disallow).
         - "Sell this resource on Community": LEAVE OFF (free plugin).
           Note: Figma's page says a PAID plugin cannot later become free. It
           does not say whether a free plugin can become paid, so decide your
           pricing before you publish.
  [ ] 8. Submit. The plugin moves to your Published section with an
         "In review" badge.
  [ ] 9. Watch the email on your Figma account: Figma sends the approval or
         rejection there. Check spam.

  description mismatch or hidden functionality, files changed without consent,

  problems, trademark misuse.
