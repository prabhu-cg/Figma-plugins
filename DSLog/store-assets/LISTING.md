## Description
DSLog tracks changes to your design system's components and variables, so you always know what changed between releases.

1. Track: pick components (selection, page or whole file) and variable collections.
2. Baseline: DSLog stores a snapshot of what you track (v1.0.0).
3. Scan: compare the file with the baseline.
4. Review: every change is classified as breaking, potentially breaking, non-breaking or informational. Add notes and migration notes, accept or reject, and confirm possible renames. Decisions carry across re-scans.
5. Release: get a recommended semantic version, a readiness checklist and a Markdown + JSON changelog.
6. History: per-release, per-component and per-token timelines, deprecations, release comparison, and an optional impact index.

Private by design: no network access, no AI, no accounts, no telemetry. Data stays in your Figma file and local plugin storage. Free.
